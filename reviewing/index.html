Review and edit

Open a note from the "Draft ready" card or from the History tab.

What you see

  • The note's title and status, for example draft or published.
  • An Audience picker, if the note has more than one audience.
  • The draft, section by section. Each bullet has chips for the issue keys it cites. Each chip links to the issue.
  • Excluded issues and cost at the bottom: the cost so far, how many issues were read, what the visibility rule excluded, what the checker dropped, and any warnings.

How bullets are checked

Before you see a draft, a checker removes any bullet that:

  • cites no issue, or cites an issue that was not in the input;
  • uses a banned term for that voice;
  • contains a name from the issues' assignees or reporters;
  • uses an internal-only issue in an audience that excludes internal changes;
  • is longer than 60 words.

If more than a fifth of the bullets are dropped, the audience's draft is written again once. Anything dropped is listed under "Dropped by validator", so nothing disappears silently.

Edit in place

  1. Choose Edit next to a section heading.
  2. The section opens as text, one bullet per line, starting with "- ". Issue keys sit in brackets at the end, for example "(ACME-4)".
  3. Change the wording, delete a line to hide that bullet, or add a line.
  4. Choose Save.

Citations are checked again when you save. A bullet without an issue key is kept and marked uncited, because you are now its author.

Regenerate an audience's draft

Choose Regenerate this audience to write that audience's draft again from the same issues. Only that audience is replaced, including any edits you made to it. Other audiences on the note, and your edits to them, stay as they are.

Regenerating uses budget, like any other draft.

Edit memory

When you publish, WhatShipped compares your published bullets with the original draft. Each bullet you changed is saved as a before and after pair for that project and voice. The newest 50 pairs are kept. The most recent few are shown to the model as house style examples next time, so later drafts move towards the way you write.

Copy-ready formats

  • Copy as Slack/Markdown
  • Copy as Markdown
  • Copy as email HTML

Each button shows the text in a box below. Select all of it and copy it. The app cannot write to your clipboard directly, because Jira does not allow it for this kind of app.

Delete a note

Delete note removes the note, its draft, its job, its publish record and any temporary data from WhatShipped's storage straight away. It does not delete a page already published in Confluence. Delete that in Confluence if you need to.

Retry

If a draft takes much longer than expected, the progress card says "Taking longer than expected" and shows Retry.
