Troubleshooting

Find the message you saw, shown exactly as WhatShipped displays it.

Message What to do
The model is busy. WhatShipped is retrying automatically. Wait a minute.
Jira asked us to slow down. WhatShipped is retrying automatically. Wait a minute.
The model returned an unexpected error. WhatShipped retried three times without success; try again later. Try later. If it repeats, contact support.
The platform's content filter declined this text. Try excluding the issue it flagged (often security detail) and generate again. Label that issue security or internal, or narrow the scope.
Generation is paused: the app vendor's model billing needs attention. Nothing you can fix on your side; the vendor has been alerted. Nothing to do on your side.
WhatShipped is missing a Jira permission scope. A Jira admin needs to re-approve the app. A Jira admin approves the update in Apps > Manage your apps.
You (or the app) cannot see this project's issues. Check project permissions. Check you, and the app, can browse the project.
The Confluence parent page no longer exists. Pick a new target in Settings. Project settings > WhatShipped > Change target, then turn paused schedules back on.
You need edit access to the target Confluence space. Ask a space admin for "Add page" permission, or choose another target.
WhatShipped's storage is full for this site. Delete old notes from History. Delete old notes, or lower retention on the admin page.
This site has used its generation budget for the month. Drafting resumes on the 1st (UTC). See Budgets.
This site's WhatShipped license is not active. A Jira admin checks the subscription in Apps > Manage your apps.
Generation took too long and was stopped. Retry with a narrower scope. Pick fewer audiences or a smaller scope and generate again.
No issues matched the visibility rule (Done or Fixed Stories, Bugs, Tasks and Improvements; not sub-tasks). Check the filter in Settings. Read the reasons shown, then choose Edit visibility rule.

Other situations

"Taking longer than expected" with a Retry button. A draft stalled. Choose Retry.

"Background jobs may be delayed". The hourly check has not run for 26 hours, so digests may be late. We are alerted.

A digest shows "missed". It started more than 3 hours after its time. It still ran.

A schedule shows "paused". Its Confluence target broke. Fix the target, then turn it back on.

Refused as too large. Over 300 issues or about $1.00. Pick fewer audiences or versions, or narrow the JQL.

My JQL was refused. You can see fewer of the matching issues than the app. Narrow the JQL to projects you can browse.

A bullet looks wrong. Check its issue chips, then edit or delete the line. If the cited issue does not support it, send us the note title and bullet text.

Copy does not reach my clipboard. This is expected. Select the text in the box and copy it.

My version description did not get a link. The link is off by default. Turn it on in Project settings. It is only added to an empty description; WhatShipped never replaces text you wrote. See Publishing.

There is no Publish button. The note was made from sample data. Generate from your own versions or JQL to publish.
